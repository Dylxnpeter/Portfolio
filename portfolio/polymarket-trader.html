core logic

The trading algorithm — step by step

01
Scan all active markets
The bot fetches all open prediction markets from the Polymarket CLOB API, filtering for markets with sufficient liquidity (volume > $10,000) and time remaining (> 24 hours to resolution).
async def scan_markets():
  markets = await clob.get_markets(status="ACTIVE")
  return [m for m in markets if
    m.volume > 10_000 and m.hours_left > 24]
02
Estimate true probability
For each market, the bot uses a combination of historical base rates, recent news sentiment (via news API), and crowd wisdom signals to estimate the "true" probability of YES resolving. This is compared to the current market price (which is itself a probability in CLOB markets).
def estimate_probability(market, news_score):
  base_rate = historical_base_rates[market.category]
  sentiment_adj = news_score * 0.15 # weight
  return (base_rate * 0.7) + (market.current_price * 0.15) + sentiment_adj
03
Calculate edge and position size
If the estimated probability differs from the market price by more than the edge threshold (default: 5%), a signal is generated. Position size is calculated using the Kelly Criterion, capped at the maximum allowed stake per trade.
def kelly_fraction(p_true, p_market):
  b = (1 / p_market) - 1 # decimal odds
  q = 1 - p_true
  kelly = (b * p_true - q) / b
  return min(kelly * 0.25, MAX_STAKE_FRACTION) # quarter-Kelly
04
Risk checks before execution
Before placing any order, the risk manager checks: daily loss limit not exceeded, no overconcentration in a single category, open positions count within limit, and portfolio correlation check to avoid correlated bets on the same underlying event.
def passes_risk_checks(signal, portfolio):
  return (
    portfolio.daily_pnl > -MAX_DAILY_LOSS and
    portfolio.open_positions < MAX_POSITIONS and
    portfolio.category_exposure(signal.cat) < MAX_CAT_EXPOSURE
  )
05
Execute limit order via CLOB API
Orders are placed as limit orders slightly inside the spread to avoid paying the full spread cost. The order is signed with the wallet's private key using EIP-712 and submitted to Polymarket's CLOB. The bot monitors fill status and cancels unfilled orders after a timeout.
async def place_order(signal):
  order = build_limit_order(
    market_id=signal.market_id,
    side=signal.side, # YES or NO
    size=signal.size_usdc,
    price=signal.limit_price # inside spread
  )
  signed = wallet.sign_order(order) # EIP-712
  return await clob.post_order(signed)
